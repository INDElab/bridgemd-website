BridgeMD

Bridging the distance between data producer and data reuser through automated metadata generation.

Datasets are documented once, for an audience their creators can only guess at. BridgeMD uses large language models to generate documentation written for a specific group of reusers — built into the repository software researchers already use.

Metadata is written without knowing who will read it

Data producers cannot anticipate every future reuser, and documenting a dataset for all of them is prohibitively costly. So datasets stay underused outside the community that made them.

In construction materials research alone, materials scientists, process engineers and civil engineers generate different data, use different methods and different terminology — while each would benefit from reusing the others' data.

The same gap runs between algorithm researchers and domain specialists in machine learning, and across the omics datasets that plant biosynthesis research needs to combine.

What the project does

01 — Generate

Documentation for a named audience

Methods that turn a dataset, its existing metadata and a reuser profile into contextualised descriptions, vocabulary mappings and example code.

02 — Integrate

Inside existing repositories

The open-source system built into OpenML and a second repository stack, so it reaches researchers where their data already lives.

03 — Validate

Evidence that it can be trusted

Quality metrics and a shared evaluation protocol that test AI-generated metadata for reliability across three very different domains.

Work packages

Six work packages over two years

Two build the system, three test it in a demanding domain, one takes it to the wider community.

Evaluation use cases

Tested where data practices differ most

Each use case is led by an expert in the field and applies the same two-step test: generate metadata with the WP1 methods, then evaluate its quality against a protocol built with WP1.

WP3

Machine learning

OpenML holds thousands of richly described datasets, yet much of that documentation is not written for the scientists who want to reuse them. A platform and a test case at once.
